# 软考刷题平台（自制工具）

备考**软考中级「系统集成项目管理工程师」**时自己搭的刷题站。纯静态、零依赖、单文件，双击就能刷，断网也能刷。

## 规模

| 模块 | 数量 |
| :--- | :--- |
| 单选题 | 1978 道（真题 29 份 1662 + 章节练习 316） |
| 案例分析 | 113 大题 / 362 问 |
| 真题年份 | 2016 – 2025，十年全覆盖 |
| 案例考次 | 2016 下 – 2026 上，共 30 个 |

## 功能

- 三种模式：章节练习 / 真题模考 / 案例分析
- 错题本，可按考点反复回刷
- 实时正确率统计
- 全部题目与逻辑内嵌在**单个 HTML 文件**里，不联网、不依赖后端

## 技术做法

题目来源是历年真题 PDF 和配套讲义，其中扫描件没有文字层，所以走了一整套 OCR 管线：

1. **OCR**：RapidOCR。进程数设为 CPU 核数（4）、每进程单线程——实测多线程在本机反而没有收益（单线程 22.3s/页 vs 多线程 22.2s/页）。37 份扫描件、104 分钟跑完。
2. **解析**：按「试题 N【答案】X【解析】」格式提取，顺带清洗水印与页眉噪音。
3. **防线**：如果选项里混入下一题的题号或答案标记，判定为 OCR 错位，整题作废，宁缺勿错。
4. **质检**：脚本扫描水印残留、答案标记残留、题干长度异常、跨题重复、答案分布是否均衡。
5. **打包**：所有数据 + 样式 + 逻辑打成单个 HTML。

OCR 的固有损失：网络图、表格题经 OCR 后只剩数字碎片，这类题已在题干里标注「原卷此处为图表/表格」，计算题无法脱离原图作答。

## 怎么用

**本地打开**：直接双击 `系统集成项目管理工程师-刷题平台.html`，不需要装任何东西。

**挂到这个站上**：把该单文件放到仓库的 `public/quiz/index.html`，即可通过 `/quiz/` 访问。这个文件默认不在 git 里（真题与讲义内容有版权考量，不适合直接进公开仓库），需要公开时自行决定。
